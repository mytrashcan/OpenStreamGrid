# Code of Conduct

OpenStreamGrid adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to all project spaces, including issues,
pull requests, discussions, and any community channels linked from this
repository.

## Expected behavior

- Be respectful and assume good intent, especially when reviewing code.
- Give and accept constructive feedback focused on the work.
- Keep discussions on topic and welcoming to newcomers.

Harassment, personal attacks, discriminatory language, and publishing others'
private information are not acceptable.

## Reporting

Report conduct concerns privately to the maintainer,
[@mytrashcan](https://github.com/mytrashcan), using the contact details on the
maintainer's GitHub profile. Do not report conduct issues in public threads.
Reports are handled confidentially, and the maintainer may edit or remove
content, or restrict participation, as described in the Contributor Covenant's
enforcement guidelines.
